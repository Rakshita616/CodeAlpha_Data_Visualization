# Data Visualization using Python

## Project Overview
This project is completed as part of the CodeAlpha Data Analytics Internship.

The objective is to analyze the restaurant tips dataset and create meaningful visualizations using Python.

## Dataset
The Tips dataset contains 244 original records and 7 columns, including:
- Total Bill
- Tip
- Sex
- Smoker
- Day
- Time
- Group Size

After removing one duplicate record, 243 records were used for analysis.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn

## Visualizations
1. Average Tip by Day – Bar Chart
2. Total Bill vs Tip – Scatter Plot
3. Distribution of Total Bills – Histogram
4. Tip Distribution by Day – Box Plot
5. Correlation Heatmap

## Key Analysis
- Average total bill: approximately 19.79
- Average tip: approximately 3.00
- Average group size: approximately 2.57
- No missing values were found.
- One duplicate record was removed.
